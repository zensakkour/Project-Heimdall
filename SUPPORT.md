# Support

## Getting Help

For usage questions, setup issues, or troubleshooting:

- Search existing GitHub issues
- Open a new issue using the appropriate issue template

## Before Opening an Issue

- Confirm you are on a recent commit from `master`
- Include your OS, Python version, and command used
- Provide logs or traceback output when possible

## Security Issues

Do not post security vulnerabilities in public issues.
Use a private channel with maintainers when available.
