# Security Policy

## Supported Versions

Project Heimdall is under active development. Security fixes are applied to the
latest code on the default branch.

## Reporting a Vulnerability

Please do not open public issues for security vulnerabilities.

Use GitHub private vulnerability reporting in the repository Security tab when
available. If that is not available, contact the maintainer directly through
GitHub and include:

- A clear description of the vulnerability
- Reproduction steps and prerequisites
- Potential impact
- Any suggested remediation

You can expect an initial response within 5 business days.
